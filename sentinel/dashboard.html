Leash —
deny means never signed.

The pre-sign firewall. Check any address against the live policy engine: on-chain blocklist, per-tx cap, daily cap, velocity and cooldown. A denied transaction is never signed — it never exists.

How enforcement works

1. agent forms an intent — to, value, chain
2. leash checks the registry blocklist + policy
3. deny → no signature is ever produced
4. allow → signed via NEAR Chain Signatures
Prompt injection can't bypass a key the model never holds.
